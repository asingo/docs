Edit Unit Type
--------------

Pada gambar sebelum nya terdapat baris yang merepresentasikan dengan elemen yang ada pada frontend. Penjelasan elemen ada pada gambar di bawah ini

 ![](http://docs.grapiku.com/storage/landing-veranda/unit/Unit-Type-Single.jpg)Nomor yang ada gambar di atas merepresentasikan elemen yang ada pada gambar di bawah ini

 ![](http://docs.grapiku.com/storage/landing-veranda/unit/Unit-Type-Single-Backend.jpg)1. Denah
2. Jenis Unit
3. Detail Unit
4. Deskripsi Unit
5. Gambar Unit
 
Untuk mengedit masing masing elemen silahkan hover bagian elemen dan klik tombol pensil untuk mengedit elemen.
