Duplikasi Laman
---------------

Pergi ke menu laman lalu akan tampil gambar seperti di bawah ini

 ![](http://docs.grapiku.com/storage/landing-veranda/duplicate/Overview.jpg)1. Klik menu ini untuk menampikan tampilan seperti gambar di atas
2. Laman ini merupakan template utama yang digunakan di dalam microsite
3. Klik bagian ini untuk melakukan pengubahan
4. Klik tombol duplicate untuk melakukan Duplikasi Laman
 
Untuk melakukan duplikasi silahkan lakukan langkah ke 4 (empat) lalu laman yang terduplikasi akan terbuat dan secara otomatis menjadi draft
