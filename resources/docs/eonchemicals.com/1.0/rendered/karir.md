Mengelola Data Karir
====================

---

Dalam mengelola data karir anda bisa menambahkan, menghapus, menyunting data karir pada Website Eon.

<a name="section-1"></a>

Pengelolaan Data Karir
----------------------

Untuk mengelola data karir, pilih menu Karir pada menu sebelah kiri dan akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/karir/Karir-1.jpg) 1. Klik menu Tambah Baru atau tombol Tambah Baru untuk menambahkan karir baru  
 2. Klik judul atau tombol Sunting untuk mengedit data karir yang sudah tersimpan sebagai draf atau yang sudah terbit   
 3. Klik tombol Tong Sampah untuk menghapus postingan yang tersimpan ataupun yang sudah terbit   
 4. Untuk mencari karir   
 5. Terdapat filtering untuk menyaring karir yang dicari sesuai kriteria

Penambahan Data Karir
---------------------

Untuk menambahkan data karir silahkan klik Tambah Baru pada petunjuk nomor 1 lalu akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/karir/Karir-2.jpg) 1. Ketik judul karir pada bagian Tambah Judul  
 2. Pada bagian Departemen, ketikkan departemen yang terkait dengan karir  
 3. Pada bagian Lokasi, masukkan lokasi karir   
 4. Pada bagian deskripsi ketikkan deskripsi karir

Penerbitan Data Karir
---------------------

Untuk menerbitkan data karir, **pastikan semua data telah ditinjau ulang** lalu klik **Terbitkan** untuk menerbitkan data karir
