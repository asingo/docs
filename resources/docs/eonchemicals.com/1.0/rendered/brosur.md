Mengelola Data Brosur
=====================

---

<a name="section-1"></a>

Dalam mengelola data brosur anda bisa menambahkan, menghapus, menyunting data produk pada Website Eon.

Pengelolaan Data Brosur
-----------------------

Untuk mengelola data brosur, pilih menu **Brosur** pada menu sebelah kiri dan akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/brosur/Brosur-1.jpg)1. Klik menu **Tambah Baru** atau tombol **Tambah Baru** untuk menambahkan brosur baru
2. Klik judul atau tombol **Sunting** untuk mengedit data brosur yang sudah tersimpan sebagai draf atau yang sudah terbit
3. Klik tombol **Tong Sampah** untuk menghapus postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari brosur
5. Terdapat filtering untuk menyaring brosur yang dicari sesuai kriteria
 
Penambahan Data Brosur
----------------------

Untuk menambahkan data brosur, silahkan klik **Tambah Baru** pada **petunjuk nomor 1** lalu akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/brosur/Brosur-2.jpg)1. Ketik judul brosur pada bagian **Judul Brosur**
2. Pada bagian data brosur, masukkan **Kode Produk** (opsional)
3. Pada bagian file brosur, klik tombol **Add File** untuk menambahkan file brosur
4. Pada bagian **Industries**, ketik industri yang terkait dengan brosur
5. Pada bagian **Product Families**, ketik divisi produk yang terkait dengan brosur
 
 <center>{warning} Pastikan Industri dan Divisi Produk terkait sudah ditambahkan!</center>Penerbitan Data Brosur
----------------------

Untuk menerbitkan data brosur, **pastikan semua data telah ditinjau ulang** lalu klik **Terbitkan** untuk menerbitkan data produk
