Mengelola Data CTA
==================

---

<a name="section-1"></a>

Dalam mengelola data CTA anda bisa menambahkan, menghapus, menyunting data CTA pada Website Eon.

Pengelolaan Data CTA
--------------------

Untuk mengelola data CTA, pilih menu **CTA Leads** pada menu sebelah kiri dan akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/cta/CTA-1.jpg)1. Klik menu **Tambah Baru** atau tombol **Tambah Baru** untuk menambahkan CTA baru
2. Klik judul atau tombol **Sunting** untuk mengedit data CTA yang sudah tersimpan sebagai draf atau yang sudah terbit
3. Klik tombol **Tong Sampah** untuk menghapus postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari CTA
5. Terdapat filtering untuk menyaring CTA yang dicari sesuai kriteria
 
Penambahan Data CTA
-------------------

Untuk menambahkan data CTA, silahkan klik **Tambah Baru** pada **petunjuk nomor 1** lalu akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/cta/CTA-2.jpg)1. Ketik **Nama CTA**, pada bagian tambahkan judul
2. Pada bagian data CTA, ketik pada bagian **Teks CTA** untuk menambahkan teks pada CTA
3. Pada field **Link CTA**, masukkan atau ketik link untuk CTA
4. Pada field **Gambar CTA**, klik **Add Image** untuk menambahkan gambar pada cta
5. Pada bagian **Gambar Andalan**, tambahkan gambar dengan klik **Tambahkan Gambar Unggulan**
 
 <center>{info} Ukuran gambar CTA dan gambar Andalan yang disarankan adalah **600x600 piksel**</center>Penerbitan Data CTA
-------------------

Untuk menerbitkan data CTA, **pastikan semua data telah ditinjau ulang** lalu klik **Terbitkan** untuk menerbitkan data CTA
