Login &amp; Logout
==================

---

<a name="section-1"></a>

Login dan Logout adalah tutorial cara masuk ke dalam panel admin website dan keluar dari akun admin website. Berikut ini langkah-langkahnya.

Login
-----

Untuk memasuki halaman panel admin, user dapat login melalui link yang diberikan oleh Tim Grapiku pada dokumentasi terpisah.

![](http://docs.grapiku.com/storage/eonchemicals/Login&Logout/Login-1.jpg)

Setelah membuka link login yang diberikan, terlihat seperti gambar di atas, berikut ini langkahnya

1. Terlihat pada form di sebelah kiri, masukkan Username/ Email Address yang terdaftar.
2. Masukkan password dengan benar.
3. <span class="fontstyle0">Setelah itu tekan tombol Log Masuk</span>
4. <span class="fontstyle0">Anda akan diminta memasukkan Kode Autentikasi 6 digit yang muncul pada aplikasi Google Authenticator saat itu juga</span>
5. <span class="fontstyle0">Tekan Authencicate untuk masuk</span><span class="fontstyle0">{info} Anda juga dapat menggunakan metode</span> <span class="fontstyle0">autentikasi lain yang terdaftar apabila Google Authenticator tidak jalan.</span>
 
Logout
------

Untuk melakukan logout pada panel admin dapat dilakukan dengan mudah.  
Setelah itu tekan tombol log masuk

![](http://docs.grapiku.com/storage/eonchemicals/Login&Logout/Login-2.jpg)

Terlihat pada gambar di atas merupakan cara untuk logout dari panel admin. Berikut ini langkahlangkahnya.

1. Pada navbar di sebelah kanan terdapat username dan icon user dapat dengan langsung di klik.
2. <span class="fontstyle0">Setelah itu akan muncul 2 pilihan yaitu edit profile dan logout seperti yang ditunjukan pada gambar.</span>
3. <span class="fontstyle0">Langkah terakhir silahkan klik tombol logout untuk keluar dari panel admin.</span>
