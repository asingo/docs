Mengelola Data SDS
==================

---

<a name="section-1"></a>

Dalam mengelola data SDS anda bisa menambahkan, menghapus, menyunting data SDS pada   
Website Eon.

Pengelolaan Data SDS
--------------------

Untuk mengelola data SDS, pilih menu **SDS** pada menu sebelah kiri dan akan tampil gambar di  
bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/sds/SDS-1.jpg)1. Klik menu **Tambah Baru** atau tombol **Tambah Baru** untuk menambahkan SDS baru
2. Klik judul atau tombol **Sunting** untuk mengedit data SDS yang sudah tersimpan sebagai draf  
    atau yang sudah terbit
3. Klik tombol **Tong Sampah** untuk menghapus postingan yang tersimpan ataupun yang sudah  
    terbit
4. Untuk mencari SDS
5. Terdapat filtering untuk menyaring SDS yang dicari sesuai kriteria
 
Penambahan Data SDS
-------------------

Untuk menambahkan data SDS, silahkan klik **Tambah Baru** pada **petunjuk nomor 1** lalu akan  
tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/sds/SDS-2.jpg)1. Ketik judul brosur pada bagian **Judul SDS**
2. Pada bagian data SDS, masukkan **Kode Produk** (opsional)
3. Pada bagian data SDS, masukkan **Topik** (opsional)
4. Pada bagian data SDS, masukkan **Nama Umum** (opsional)
5. Pada bagian data SDS, pilih jenis File, dibawahnya akan secara otomatis terdapat kondisional  
    inputan URL SDS atau upload file SDS. Direkomendasikan untuk mengisi URL SDS  
    berdasarkan data SDS di ftp.eonchemicals.com (contoh:  
    https://sds.eonchemicals.com/sds-abc.pdf) dibandingkan upload file SDS
6. Pada bagian **Industries**, ketik industri yang terkait dengan SDS
7. Pada bagian **Product Families**, ketik divisi produk yang terkait dengan SDS   
       
     {warning} Pastikan Industri dan Divisi Produk terkait sudah ditambahkan!
 
Penerbitan Data SDS
-------------------

Untuk menerbitkan data SDS, **pastikan semua data telah ditinjau ulang lalu** klik **Terbitkan**  
untuk menerbitkan data SDS
