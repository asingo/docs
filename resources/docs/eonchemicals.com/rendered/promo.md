Mengelola Data Promo
====================

---

Dalam mengelola data promo anda bisa menambahkan, menghapus, menyunting data promo  
pada Website Eon.

<a name="section-1"></a>

Pengelolaan Data Promo
----------------------

Untuk mengelola data promo, pilih menu Promo pada menu sebelah kiri dan akan tampil gambar  
di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/promo/Promo-1.jpg)1. Klik menu Tambah Baru atau tombol Tambah Baru untuk menambahkan promo baru
2. Klik judul atau tombol Sunting untuk mengedit data promo yang sudah tersimpan sebagai draf atau yang sudah terbit
3. Klik tombol Tong Sampah untuk menghapus postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari promo
5. Terdapat filtering untuk menyaring promo yang dicari sesuai kriteri
 
   
  
Penambahan Data Promo
---------------------

Untuk menambahkan data promo, silahkan klik **Tambah Baru** pada **petunjuk nomor 1** lalu akan tampil gambar di bawah ini

 ![](http://docs.grapiku.com/storage/eonchemicals/promo/Promo-2.jpg)1. Ketik judul promo pada bagian **Tambah Judul**
2. Pada bagian deskripsi pilih **Backend Editor** untuk membuat layout menggunakan WPBakery Page Builder   
       
     {info} Untuk tutorial cara menggunakan WPBakery Page Builder klik disini
 
Penerbitan Data Promo
---------------------

Untuk menerbitkan data promo, pastikan semua data telah ditinjau ulang lalu klik Terbitkan   
untuk menerbitkan data promo
