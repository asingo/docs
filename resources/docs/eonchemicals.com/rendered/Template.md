Template
========

---

<a name="section-1"></a>

Website Eonchemicals.com dirancang secara modular berbasis template pada backendnya untuk mempermudah development dan maintenance. Template merupakan sebuah layouting tetap yang dapat diatur sedemikian rupa sesuai dengan Custom Post Typenya. Misalnya Template Single Industri untuk mengatur layout seluruh Post Industri, Template Single Artikel untuk mengatur layout seluruh Post Artikel.

Pengelolaan Template
--------------------
