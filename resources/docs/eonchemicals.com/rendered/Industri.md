Pengelolaan Data Industri
-------------------------

Untuk mengelola Industri, pilih menu Industri pada menu sebelah kiri, dan akan tampil seperti gambar di bawah ini

![](http://docs.grapiku.com/storage/eonchemicals/Industri/Industri-1.jpg)

1. Klik menu **Tambah Baru** atau tombol **Tambah Baru** untuk menambahkan industri baru.
2. Klik judul atau klik tombol **Sunting** untuk me<span class="fontstyle0">ngedit industri yang sudah tersimpan sebagai draf maupun yang sudah terbit.</span>
3. <span class="fontstyle0">dhuehfhyf</span>
4. <span class="fontstyle0"><span class="fontstyle0">Klik tombol </span><span class="fontstyle2">Tong Sampah </span><span class="fontstyle0">untuk menghapus postingan yang tersimpan ataupun yang sudah terbit.</span></span>
5. <span class="fontstyle0"><span class="fontstyle0">Untuk mencari industri.</span></span>
6. <span class="fontstyle0"><span class="fontstyle0">Terdapat filtering untuk menyaring industri yang ingin dicari sesuai dengan kriteria.</span></span>
 
Penambahan Data Masalah Industri
--------------------------------

Untuk menambahkan data industri, silahkan klik tombol **Tambah Baru** yang berada pada gambar diatas **petunjuk nomor 1** lalu akan tampil gambar di bawah ini:

![](http://docs.grapiku.com/storage/eonchemicals/Industri/Industri-2.jpg)

1. Ketik Nama Industri pada kolom **Nama Industri**
2. <span class="fontstyle0">Pada Field Deskripsi silahkan masukkan Deskripsi Industri</span>
3. <span class="fontstyle0"><span class="fontstyle0">Pada Box Gambar Andalan silahkan klik </span><span class="fontstyle2">**Tetapkan Gambar Unggulan** </span><span class="fontstyle0">untuk memilih gambar utama yang akan tampil pada industri</span></span>
 
 <center>{info} Ukuran gambar yang disarankan adalah **1712x1712 piksel** </center> 4. Untuk menambah data masalah klik tombol **Tambah Baris** pada bagian data masalah. Penjelasan lebih lanjut Klik Disini.  
<span class="fontstyle0"> 5. Tambah Ikon Industri dengan cara klik tombol </span>**<span class="fontstyle2">Add Image</span>**  
<span class="fontstyle2"><span class="fontstyle0"> 6. Masukkan teks yang digunakan sebagai headline dengan menambahkan pada bagian </span>**<span class="fontstyle2">Headline Industri</span>**   
</span>  
Penambahan Data Industri
------------------------

![](http://docs.grapiku.com/storage/eonchemicals/Industri/Industri-3.jpg)

Untuk menambahkan data masalah pada industri seperti contoh di atas. Langkah pertama silahkan klik tombol **Tambah Baris** pada bagian data masalah yang sesuai dengan **petunjuk** **nomor 4** di atas

![](http://docs.grapiku.com/storage/eonchemicals/Industri/Industri-4.jpg)

1. Silahkan pilih equipment yang terkait dengan masalah
2. <span class="fontstyle0">Klik Tambah Baris untuk menambah baris Problem dan Solusi</span>
3. <span class="fontstyle0"><span class="fontstyle0">Untuk menambahkan data problem dan solusi, klik pada bagian </span><span class="fontstyle2">**Tambah Baris** </span><span class="fontstyle0">yang ada di dalam kolom Problem dan Solusi</span></span><span class="fontstyle0">   
    ![](http://docs.grapiku.com/storage/eonchemicals/Industri/Industri-5.jpg)</span>
4. Silahkan ketikkan Masalah dan Produk yang sesuai
5. <span class="fontstyle0">Untuk menambahkan baris pada Problem dan Solusi, klik pada bagian </span><span class="fontstyle2">Tambah Baris </span><span class="fontstyle0">yang ada di dalam kolom Problem dan Solusi</span>
 
 
 
Penerbitan Data Industri
------------------------

Untuk penerbitan data Industri, pastikan semua data produk telah ditinjau ulang, setelah itu klik tombol Terbitkan untuk menerbitkan dan menyimpan Data Industri.
