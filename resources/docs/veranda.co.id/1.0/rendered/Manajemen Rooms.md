Manajemen Rooms 
================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen rooms

---

Untuk mengelola pada halaman rooms seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen rooms dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p2.png)Untuk mengakses halaman manajemen rooms dapat diakses dengan mengeklik menu rooms yang berada pada sidebar seperti gambar dibawah :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p3.png)Setelah mengeklik maka akan diarahkan ke halaman manajemen rooms seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p4.png)Berikut pembahasan tutorial pada gambar diatas :

1. ADD NEW POST, digunakan untuk menambahkan room baru.
2. Status Post, digunakan untuk mengelompokan posts berdasarkan status post tersebut.
3. Filter, digunakan untuk mefilter post, disini terdapat 4 filter yang dapat digunakan.
4. Search, digunakan untuk mencari suatu post.
5. Title, digunakan untuk mengelola suatu post disini terdapat 4 button yaitu :   
     - EDIT, digunakan untuk mengedit suatu post.   
     - TRASH, digunakan untuk menghapus suatu post.   
     - VIEW, digunakan untuk melihat detail suatu post.  
     - CLONE, digunakan untuk menduplikasi suatu post.   
     - EDIT WITH WPBAKERY PAGE BUILDER, digunakan untuk mengedit tampilan (pada button ini tidak direkomendasikan untuk digunakan).
6. Date, digunakan untuk mengetahui tanggal dan waktu post itu dipublish
7. Seo score dan Readability score, terdapat 3 warna yaitu :   
     - Merah, scorenya kurang bagus.   
    \- Orange, scorenya lumayan bagus.   
    \- Hijau, scorenya bagus.
 
Membuat Suatu Room
------------------

Untuk membuat suatu room baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p5.png)Berikut pembahasan dari tutorial diatas :

1. Add title, digunakan untuk menambahkan judul baru pada suatu room.
2. Expert, digunakan untuk menambahkan deskripsi singkat.
3. Link Booking, digunakan untuk menambahkan link/url booking pada room.
4. Description, digunakan untuk menambahkan deskripsi untuk suatu room.
5. Gallery, digunakan untuk menambahkan foto slider yang ada pada tiap single room.   
     &gt;{info} Gambar gallery menggunakan ukuran 1920x1080px
6. Room Facilities, digunakan untuk menambahkan fasilitas unggulan di grid room homepage.
7. Single Facilities, digunakan untuk menambahkan fasilitas pada suatu room.
8. Featured Image, digunakan untuk menambahkan gambar utama pada suatu grid.   
     &gt;{info} Gambar gallery menggunakan ukuran 2560x1707px
9. Category, Pilih room untuk pembuatan room digunakan untuk templating.
10. Publish, digunakan untuk menerbitkan/mempublish room yang baru dibuat
 
Mengedit Suatu Room
-------------------

Untuk mengedit suatu room baru dapat dengan cara klik button edit, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Rooms/p6.png)Berikut pembahasan dari tutorial diatas :

1. Add title, digunakan untuk mengedit judul baru pada suatu room.
2. Permalink, digunakan untuk mengedit link yang terdahulu.
3. Expert, digunakan untuk mengedit deskripsi singkat.
4. Link Booking, digunakan untuk mengedit link/url booking pada room.
5. Description, digunakan untuk mengedit deskripsi untuk suatu room.
6. Gallery, digunakan untuk mengedit foto slider yang ada pada tiap single room.   
     &gt;{info} Gambar gallery menggunakan ukuran 1920x1080px
7. Room Facilities, digunakan untuk mengedit fasilitas unggulan di grid room homepage.
8. Single Facilities, digunakan untuk mengedit fasilitas pada suatu room.
9. Featured Image, digunakan untuk mengedit gambar utama pada suatu grid.   
     &gt;{info} Gambar gallery menggunakan ukuran 2560x1707px
10. Category, Pilih room untuk pembuatan room digunakan untuk templating.
11. Publish, digunakan untuk menerbitkan/mempublish room yang telah diupdate.
