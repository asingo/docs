========================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen signature food

---

Pertama-tama untuk mengakses halaman untuk mengelola manajemen Signature Food dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

Untuk mengakses halaman manajemen Signature Food dapat diakses dengan menu sidebar disebelah kiri melalui tutorial dibawah yaitu :

// gambar belom ada

1. Arahkan kursor mouse pada menu Signature Food 2.
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Signature Food
 
Setelah masuk kehalaman All Signature Food seperti gambar dibawah ini, berikut pembahasannya :

// gambar belom ada

1. ADD NEW POST, digunakan untuk menambahkan signature food baru.
2. Status signature food, fitur disini berfungsi sebagai mengoordinasi status pada signature food beserta akumulasi masing-masing status.
3. Filter, digunakan untuk mefilter semua signature food, disini terdapat 4 filter yang disediakan.
4. Search, berfungsi sebagai form pencarian untuk semua signature food.
5. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat beberapa button seperti :   
     - Edit, digunakan untuk mengedit suatu post yang dipilih. - Trash, digunakan untuk menghapus suatu post yang dipilih.   
     - View/Preview, digunakan untuk melihat suatu post yang telah dibuat.   
     - Clone, digunakan untuk menduplicate post yang sudah ada.   
     - New Draft, digunakan untuk mendrafting suatu post.
6. Date, berfungsi untuk melihat post ini dipublish/diupdated tanggal dan jam berapa.
7. Seo score dan Readability score, terdapat 3 warna yaitu :   
     - Merah, scorenya kurang bagus.   
     - Orange, scorenya lumayan bagus.   
     - Hijau, scorenya bagus.
 
Membuat Signature Food
----------------------

Untuk membuat post baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

// gambar belom ada

1. Add title, digunakan untuk menambahkan title pada post.
2. Description, digunakan untuk menambahkan deskripsi pada signature food secara informatif
3. Excerpt, digunakan untuk menambahkan deskripsi singkat pada signature food.
4. Fetaured Image, digunakan untuk menambahkan gambar utama yang akan ditampilkan pada list signature food.   
     &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 600x600px.
5. Publish, digunakan untuk mempublish post yang sudah dibuat.
 
Mengedit Signature Food
-----------------------

Untuk mengedit suatu signature food dapat dilakukan dengan cara mengeklik title/button edit dari suatu post dihalaman all signature food, kemudian akan tampil seperti gambar dibawah ini :

// gambar belom ada

1. Add title, digunakan untuk mengedit title pada post.
2. Permalink, digunakan untuk mengedit link yang sudah ada.
3. Description, digunakan untuk mengedit deskripsi pada signature food secara informatif
4. Excerpt, digunakan untuk mengedit deskripsi singkat pada signature food.
5. Fetaured Image, digunakan untuk mengedit gambar utama yang akan ditampilkan pada list signature food.   
     &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 600x600px.
6. Publish, digunakan untuk update post yang sudah dibuat.
