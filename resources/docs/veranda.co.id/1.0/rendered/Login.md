Login
=====

---

<a name="section-1"></a>

Berikut merupakan tutorial untuk melakukan login pada panel admin veranda.

Login
-----

Langkah pertama, buka url yang diberikan oleh tim grapiku untuk mengakses panel login, maka akan tampak seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/login/p1.png)Selanjutnya silahkan isi form login sesuai dengan langkah-langkah dibawah ini :

1. Masukkan Nama Pengguna atau Alamat Email yang terdaftar pada panel admin.
2. Masukkan Password sesuai dengan akun yang terdaftar.
3. Tekan tombol Log Masuk.
 
Setelah itu maka diredirect ke halaman dashboard seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/login/p2.png)Setelah mengikuti tutorial diatas maka anda sudah berhasil login ke halaman dashboard admin.
