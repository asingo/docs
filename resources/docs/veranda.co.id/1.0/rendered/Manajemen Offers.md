Manajemen Offers
================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen offers

---

Untuk mengelola pada halaman offers seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen Offers dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p2.png)Untuk mengakses halaman manajemen offers dapat diakses dengan menu sidebar disebelah kiri melalui tutorial dibawah yaitu :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p3.png)1. Arahkan kursor mouse pada menu Offers
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Offers
 
Setelah masuk kehalaman All Offers seperti gambar dibawah ini, berikut pembahasannya :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p4.png)1. ADD NEW POST, digunakan untuk menambahkan offer baru.
2. Status offers, fitur disini berfungsi sebagai mengoordinasi status pada offers beserta akumulasi masing-masing status.
3. Filter, digunakan untuk mefilter semua offers, disini terdapat 4 filter yang disediakan.
4. Search, berfungsi sebagai form pencarian untuk semua offers.
5. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat beberapa button seperti :   
     - Edit, digunakan untuk mengedit suatu post yang dipilih.   
     - Trash, digunakan untuk menghapus suatu post yang dipilih.   
     - View/Preview, digunakan untuk melihat suatu post yang telah dibuat.   
     - Clone, digunakan untuk menduplicate post yang sudah ada.   
     - New Draft, digunakan untuk mendrafting suatu post.
6. Date, berfungsi untuk melihat post ini dipublish/diupdated tanggal dan jam berapa.
7. Seo score dan Readability score, terdapat 3 warna yaitu :   
     - Merah, scorenya kurang bagus.   
     - Orange, scorenya lumayan bagus.   
     - Hijau, scorenya bagus.
 
Membuat Offers
--------------

Untuk membuat post baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p5.png)1. Add title, digunakan untuk menambahkan title pada post.
2. Offers Description, digunakan untuk menambahkan deskripsi pada offers secara informatif
3. Link Booking, digunakan untuk menambahkan link booking pada suatu offers.
4. Offers Category, digunakan untuk memberikan category pada suatu offer.
5. Fetaured Image, digunakan untuk menambahkan gambar utama yang akan ditampilkan pada list offers.
 
 
 &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1024x1024px.  
  
 6. Publish, digunakan untuk mempublish post yang sudah dibuat.

Mengedit Offers
---------------

Untuk mengedit suatu offers dapat dilakukan dengan cara mengeklik title/button edit dari suatu post dihalaman all offers, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Offers/p6.png)1. Add title, digunakan untuk mengedit title pada post.
2. Permalink, digunakan untuk mengedit link yang sudah ada.
3. Offers Description, digunakan untuk mengedit deskripsi pada offers secara informatif
4. Link Booking, digunakan untuk mengedit link booking pada suatu offers.
5. Offers Category, digunakan untuk mengedit category pada suatu offer.
6. Fetaured Image, digunakan untuk mengedit gambar utama yang akan ditampilkan pada list offers.   
     &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1024x1024px.
7. Publish, digunakan untuk mempublish post yang sudah diedit
