Media Coverages
===============

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen media coverages

---

Untuk mengelola pada halaman media coverages seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/veranda.co.id/Media Coverages/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen media coverages dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Media Coverages/p2.png)Untuk mengakses halaman manajemen media coverages dapat diakses dengan menu sidebar disebelah kiri melalui tutorial dibawah yaitu :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Media Coverages/p3.png)1. Arahkan kursor mouse pada menu Posts
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Posts
 
Setelah masuk kehalaman All Posts seperti gambar dibawah ini, berikut pembahasannya :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Media Coverages/p4.png)1. ADD NEW POST, digunakan untuk menambahkan media coverage baru.
2. Status media coverage, fitur disini berfungsi sebagai mengoordinasi status pada media coverage beserta akumulasi masing-masing status.
3. Filter, digunakan untuk mefilter semua media coverage, disini terdapat 5 filter yang disediakan.
4. Search, berfungsi sebagai form pencarian untuk semua media coverage.
5. Pagination, digunakan untuk mengakumulasi semua page beserta melimit item untuk ditampilkan supaya tidak terlalu banyak yang ditampilkan
6. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat beberapa button seperti :   
     - Edit, digunakan untuk mengedit suatu post yang dipilih.   
     - Trash, digunakan untuk menghapus suatu post yang dipilih.   
     - View/Preview, digunakan untuk melihat suatu post yang telah dibuat.   
     - Clone, digunakan untuk menduplicate post yang sudah ada.   
     - New Draft, digunakan untuk mendrafting suatu post.   
     - Rewrite &amp; Republish, disini fitur ini mirip dengan edit yaitu digunakan untuk mengedit suatu post.
7. Author, digunakan untuk mengetahui siapa yang membuat post tersebut.
8. Categories, digunakan untuk mengetahui post tersebut berkategori apa.
9. Date, digunakan untuk mengetahui tanggal publish dari suatu post tersebut.
10. Seo score dan Readability score, terdapat 3 warna yaitu :   
     - Merah, scorenya kurang bagus.   
     - Orange, scorenya lumayan bagus.   
     - Hijau, scorenya bagus.
