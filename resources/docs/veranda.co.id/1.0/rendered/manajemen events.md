Manajemen events
================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen events

---

Untuk mengelola pada halaman events seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Events/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen events dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Events/p2.png)Untuk mengakses halaman manajemen events dapat diakses dengan menu sidebar disebelah kiri melalui tutorial dibawah yaitu :

![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Events/p3.png)

1. Arahkan kursor mouse pada menu Events
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Events
