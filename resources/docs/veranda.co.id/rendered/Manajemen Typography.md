Manajemen Typography
====================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen typography

---

Untuk mengelola typography dapat mengikuti langkah-langkah sebagai berikut :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Typography/p1.png)Pertama arahkan kursor mouse pada menu Appearance kemudian pilih submenu Customize seperti gambar diatas, maka akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Typography/p2.png)  
  
Setelah itu pilih menu Typography, maka akan tampil seperti gambar dibawah ini : ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Typography/p3.png)Setelah itu pilih salah satu typography untuk diedit, pada kasus ini kami akan mengedit pada bagian H2, langsung saja klik H2 pada menu, maka akan tampil seperti gambar dibawah ini:

 ![](http://docs.grapiku.com/storage/veranda.co.id/Manajemen Typography/p4.png)Pada tampilan box setting h2 tersebut terdapat banyak opsional untuk melakukan editing secara global pada tag h2. setelah melakukan perubahan yang dibutuhkan setelah itu langsung saja tekan tombol terbitkan.
