Pengelolaan Popup
-----------------

![](http://docs.grapiku.com/storage/nissin/popup/1splash.jpg)  
Untuk mengelola popup klik menu **IMAGE POPUP** pada bilah menu kiri seperti gambar di bawah ini

 ![](https://docs.grapiku.com/storage/nissin/popup/1-click-menu.png)Maka akan muncul tampilan seperti di bawah ini.

 ![](https://docs.grapiku.com/storage/nissin/popup/2-save-popup.png)Berikut ini adalah deskripsi dari elemen di atas

1. Klik Upload untuk mengubah gambar Popup **Bahasa Inggris**
2. Klik Upload untuk mengubah gambar Popup **Bahasa Indonesia**
3. Klik **Save Changes** untuk menyimpan perubahan
