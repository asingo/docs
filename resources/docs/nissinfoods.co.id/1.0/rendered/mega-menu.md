Pengelolaan Mega Menu
---------------------

LOG IN ke dasbor admin lalu pergi ke menu MEGA MENU seperti yang ditandai pada gambar di bawah ini

 ![](https://docs.grapiku.com/storage/nissin/mega-menu/1-menu.jpg)   
Lalu akan tampil gambar seperti di bawah ini.

 ![](https://docs.grapiku.com/storage/nissin/mega-menu/2-mega.jpg)Nomor atau tanda diatas merepresentasikan isi dari menu di bawah ini

 ![](https://docs.grapiku.com/storage/nissin/mega-menu/3-representasi.jpg)Setelah klik judul atau edit maka akan muncul tampilan seperti ini:

 ![](https://docs.grapiku.com/storage/nissin/mega-menu/4-edit.jpg)   
1. Klik tombol nomor 1 untuk menampilkan daftar produk
2. Pada box nomor 2 silahkan cari produk yang ingin di tambahkan ke mega menu
3. Setelah selesai klik update pada nomor 3
