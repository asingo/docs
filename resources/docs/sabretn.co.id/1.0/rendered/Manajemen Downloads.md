Untuk mengakses halaman manajemen download dapat diakses dengan menu sidebar disebelah kiri setelah itu maka akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Downloads/download-1.jpg)Berikut penjelasan dari halaman list download :

1. ADD NEW POST, digunakan untuk menambahkan download baru.
2. Group posts, fitur disini berfungsi sebagai mengoordinasi status pada download beserta akumulasi masing-masing status.
3. Search, berfungsi sebagai form pencarian untuk semua downloads.
4. Filter, digunakan untuk mefilter semua downloads, disini terdapat 2 filter yang disediakan.
5. Pagination, digunakan untuk mengakumulasi semua page beserta melimit item untuk ditampilkan supaya tidak terlalu banyak yang ditampilkan
6. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat beberapa button seperti :   
     - Edit, digunakan untuk mengedit suatu post yang dipilih.   
     - Trash, digunakan untuk menghapus suatu post yang dipilih.
 
Menambahkan Download
--------------------

Untuk menambahkan download baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Downloads/download-2.jpg)Berikut penjelasan dari tutorial gambar diatas :

1. Add title, digunakan untuk menambahkan title baru.
2. URL File Download, tambahkan url file download dapat mendapatkan file dari media dan ambil url file yang telah diupload.
3. File Category, tambahkan category untuk download baru ini.
4. File Type, tambahkan tipe file yang akan digunakan
5. Publish, setelah mengisi form yang wajib diisi dan untuk mempublish dapat menekan tombol publish.
 
Mengedit Download
-----------------

Untuk mengedit suatu download dapat dengan cara klik tombol Edit, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Downloads/download-3.jpg)Untuk melakukan edit suatu download dapat mengikuti tutorial dibawah ini :

1. Edit Title, digunakan untuk mengedit suatu title dari download.
2. URL File Download, digunakan untuk mengedit suatu url file download.
3. File Category, digunakan untuk mengedit suatu file category.
4. File Type, digunakan untuk mengedit suatu file type.
5. Setelah melakukan edit yang diperlukan, untuk melakukan update suatu post download dapat dilakukan dengan menekan tombol Update.
