Kelola Menu Solusi
==================

Dalam langkah-langkah kali ini akan membahas tentang cara kelola menu solusi

---

Untuk menambah dan menghapus menu solusi pada navbar seperti gambar dibawah dapat mengikuti langkah-langkah berikut:

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Solusions/menu-solusi-1.jpg)Pertama buka dashboard terlebih dahulu seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-2.jpg)Setelah itu buka menu Solutions pada menu disidebar sebelah kiri. Setelah itu tambahkan solusi baru, penambahan solusi baru dapat mengikuti pada tutorial Solutions . disini saya akan menggunakan contoh yaitu Test seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-3.jpg)Setelah membuat sebuah Test seperti gambar diatas, selanjutnya yaitu menambahkan Test ke menu dengan cara yaitu :  
  
1\. Arahkan kursor mouse ke menu Apperance pada sidebar maka akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-4.jpg)2\. Klik Menus seperti yang sudah ditandai pada gambar diatas, maka tampilannya akan seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-5.jpg)3\. Untuk menambah, mengedit, menghapus item pada menu, pertama pilih Select a menu to edit kemudian akan muncul list seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-6.jpg)Pada kasus ini kita akan menambahkan Item Test ke menu solusi, untuk menambahkan item Test ada yang perlu diperhatikan yaitu kita harus menambahkan item baru kedalam 4 Menu sesuai yang ditandai pada gambar diatas yaitu :  
\- Main Menu (Primary English) - Menu Mobile (Mobile Indonesia)   
\- Menu Mobile English (Mobile English)   
\- Menu Utama (Primary Indonesia Dalam kasus ini kita akan membuat tutorial menambahkan item ke salah satu menu yaitu Main Menu (Primary English) sebagai berikut :

 1. Klik Main Menu (Primary English) terlebih dahulu kemudian tekan tombol SELECT  
2.Maka akan menampilkan list menu dari Main Menu ini seperti gambar dibawah ini :  
  
![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-7.jpg) 3. Setelah itu pilih Solutions pada sidebar maka akan muncul list dari solutions seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-8.jpg)4\. Pada gambar diatas item yang telah kita buat di Solusions telah muncul yaitu Test, kemudian pilih Test setelah itu ADD TO MENU maka item tersebut akan masuk ke menu sebagai item baru seperti gambar dibawah ini:

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-9.jpg)5\. Item yang baru ditambahkan akan muncul dibawah sendiri dari list all menu seperti gambar diatas. Untuk menyesuaikan lokasi dari item baru dapat dilakukan dengan cara drag and drop pada lokasi yang diinginkan, seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-9.jpg)6\. Pada kali ini saya menambahkan menu dengan drag and drop dan menjadi sub menu dari Solutions gambar diatas, setelah sudah cocok dengan yang diinginkan kemudian klik button save seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-10.jpg) ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-11.jpg)7\. Setelah melakukan Save Menu, maka menu yang dibuat sudah tersimpan dan dapat dilihat pada tampilan frontend seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Kelola Menu Solusi/menu-solusi-12.jpg)Pada kali ini kita sudah membuat sub menu untuk tampilah bahasa inggris. jika sudah tampil seperti gambar diatas maka sudah tutorial untuk membuat menu baru sudah selesai.
