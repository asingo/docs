Manajemen Solusions
===================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen solusi

---

Untuk mengelola pada halaman solusi seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

belom ada gambar  
  
Pertama-tama untuk mengakses halaman untuk mengelola manajemen solusi dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

belom ada gambar  
  
Selanjutnya silahkan klik menu Solutions pada sidebar disebelah kiri seperti yang terlihat pada gambar diatas. Maka akan diredirect kehalaman list solusi, seperti gambar dibawah ini :

 belom ada gambar  
  
Pada gambar diatas terdapat beberapa menu berikut penjelasannya :  
1. ADD NEW POST, digunakan untuk menambahkan solutions baru.
2. Group post, digunakan untuk mengelompokan post berdasarkan status post itu sendiri.
3. Filter post, digunakan untuk memfilter berdasarkan tanggal dibuat/score seo maupun score readability.
4. Search Solutions, digunakan sebagai kolom pencarian.
5. Count, menampilkan jumlah post yang sudah dibuat beserta pagination.
6. Title, pada title post terdapat beberapa tombol, berikut penjelasannya :   
     - Edit, digunakan untuk mengedit suatu post.   
     - Trash, digunakan untuk menghapus suatu post.   
     - View, digunakan untuk melihat detail suatu post.   
     - Edit with wpbakery page builder, digunakan untuk mengubah tampilan pada suatu post (untuk tombol ini tidak direkomendasikan).
7. Terdapat 2 icon yaitu SEO score dan Readability score, berikut penjelasannya :   
     - SEO score digunakan untuk melihat seo score ini bagus atau tidaknya. jika warnanya merah maka seonya buruk, jika warnanya orange maka seonya lumayan , dan jika warnanya hijau maka seonya bagus.   
     - Readability score digunakan untuk melihat readability scoreini bagus atau tidaknya. jika warnanya merah maka seonya buruk, jika warnanya orange maka seonya lumayan, dan jika warnanya hijau maka seonya bagus.
8. Languages, digunakan untuk mengetahui post ini menggunakan bahasa indonesia atau inggris.
 
Membuat Post Solutions
----------------------

Untuk membuat post baru dapat dengan cara klik clone pada salah satu list solutions kemudian akan tampil seperti gambar dibawah ini :

belom ada gambar

disini sebagai contoh saya melakukan clone terhadap Sabre Red 360, setelah muncul seperti gambar diatas maka langkah selanjutnya ada mengedit page, berikut tutorialnya :

gambar belomm

Untuk melakukan edit pada suatu solution dapat dilihat pada gambar diatas terdapat 2 gambar yaitu sebelah kiri untuk tools editors dan disebelah kanan adalah hasil dari editor tersebut, berikut langkah - langkahnya :

1. Languages, digunakan untuk mengeset bahasa pada post, disini terdapat 2 bahasa yaitu bahasa indonesia dan bahasa inggris.
2. Title, digunakan untuk mengeset title pada post.
3. Permalink, digunakan untuk mengeset url/link yang akan digunakan.
4. no. 4, digunakan untuk mengeset title pada post seperti pada tampilan section-1.
5. no. 5, digunakan untuk mengeset desc pada section-1.
6. no. 6, digunakan untuk mengeset url pada button DOWNLOAD.
7. no. 7, digunakan untuk mengeset url pada button LIHAT DEMO.
8. no. 8, digunakan untuk mengeset gambar utama pada post.   
     &gt;{info} Ukuran gambar utama 1280 x128
9. no. 9, digunakan untuk title pada section-2.
10. no. 10, digunakan untuk deskripsi pada section-2.
11. no. 11, digunakan untuk mengeset url pada button BACA PADUAN.
12. no. 12, digunakan untuk mengeset title pada section-3.
13. no. 13, digunakan untuk mengeset deskripsi pada section-3.
14. no. 14, digunakan untuk mengeset url tombol DOWNLOAD UNTUK WINDOWS.
15. no. 15, digunakan untuk mengeset url tombol DOWNLOAD UNTUK MAC.
16. no. 16, digunakan untuk mengeset video.
17. no. 17, digunakan untuk mengeset title pada section-3.
18. no. 18, digunakan untuk mengeset deskripsi pada section-3.
19. no. 19, digunakan untuk mengeset title pada section-4.
20. no. 20, digunakan untuk mengeset list item pada section-4.
21. no. 21, digunakan untuk mengeset testimonial pada section-5.
22. no. 22, digunakan untuk mengeset text pada cta section-6.
23. no. 23, digunakan untuk mengeset url tombol HUBUNGI KAMI.
24. Seo title, digunakan untuk mengatur seo title yang berguna untuk pencarian digoogle.  
     &gt;{info} Pastikan bar seo title bewarna hijau, dikarenakan jika bewarna merah atau kuning dapat dipastikan seo title kurang bagus.
25. Slug, digunakan untuk mengatur slug yang berguna untuk pencarian digoogle.
26. Meta Deskripsi, digunakan untuk mengatur meta deskripsi yang berguna untuk pencarian digoogle.   
     &gt;{info} Pastikan bar seo title bewarna hijau, dikarenakan jika bewarna merah atau kuning dapat dipastikan seo title kurang bagus.
27. Excerpt, digunakan untuk memberikan deskripsi singkat terhadap suatu post.
28. Setelah semua terisi dengan baik maka langkah selanjutnya yaitu mempublish dengan menekan tombol Update
