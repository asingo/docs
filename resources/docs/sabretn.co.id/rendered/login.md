Login
=====

---

<a name="section-1"></a>

Berikut merupakan tutorial untuk melakukan login pada panel admin sabretn.

Login
-----

Langkah pertama, buka url yang diberikan oleh tim grapiku untuk mengakses panel login, maka akan tampak seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/login/login-1.jpg)Selanjutnya silahkan isi form login sesuai dengan langkah-langkah dibawah ini :

1. Masukkan Nama Pengguna atau Alamat Email yang terdaftar pada panel admin.
2. Masukkan Password sesuai dengan akun yang terdaftar.
3. Tekan tombol Log Masuk.
 
Setelah itu maka akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/login/login-2.jpg)Untuk melakukan login user juga memerlukan kode authentication yang bisa didapatkan oleh divisi yang memegang email authentication. setelah mendapatkan kode authentication dapat mengikuti step dibawah ini :

1. Masukkan kode authentication yang didapatkan.
2. Klik tombol Authenticate untuk melakukan login ke dashboard, jika kode tidak valid maka tidak dapat login ke dashboard.
 
Setelah kode authenticate telah disubmit maka akan diredirect ke halaman dashboard seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/login/login-3.png)Setelah mengikuti tutorial diatas maka anda sudah berhasil login ke halaman dashboard admin.
