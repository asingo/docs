Manajemen Careers
=================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen careers

---

Untuk mengelola pada halaman careers seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Careers/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen careers dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Careers/careers-1.jpg)Untuk mengakses halaman manajemen careers dapat diakses dengan mengeklik menu careers yang berada pada sidebar seperti gambar diatas, setelah mengeklik maka akan diarahkan ke halaman manajemen careers seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Careers/careers-2.jpg)Berikut pembahasan tutorial pada gambar diatas :

1. ADD NEW POST, digunakan untuk menambahkan post baru dari suatu career.
2. Group Post, digunakan untuk mengelompokan posts berdasarkan status post.
3. Filter, digunakan untuk mefilter post, disini terdapat 4 filter yang dapat digunakan.
4. Search, digunakan untuk mencari suatu post.
5. Title, digunakan untuk mengelola suatu post disini terdapat 4 button yaitu :   
     - EDIT, digunakan untuk mengedit suatu post.   
     - TRASH, digunakan untuk menghapus suatu post.   
     - VIEW, digunakan untuk melihat detail suatu post.   
     - EDIT WITH WPBAKERY PAGE BUILDER, digunakan untuk mengedit tampilan (pada button ini tidak direkomendasikan untuk digunakan).
6. Seo score dan Readability score, terdapat 3 warna yaitu :   
     - Merah, scorenya kurang bagus.   
     - Orange, scorenya lumayan bagus.   
     - Hijau, scorenya bagus.
 
Membuat Suatu Career
--------------------

Untuk membuat suatu career baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Careers/careers-3.jpg)Berikut pembahasan dari tutorial diatas :

1. Add title, digunakan untuk menambahkan judul baru pada suatu career.
2. Division, pilih divisions yang tersedia pada radion button dan pilih divisi yang akan dibuka untuk lowongan baru.
3. Location, digunakan untuk memilih lokasi dari suatu career yang akan dibuka.
4. Work Type, digunakan untuk memilih jenis pekerjaan ini kontraknya bersifat full time atau part time.
5. Job Description, digunakan untuk memberi penjelasan tentang job desk dari suatu career.
6. Link, digunakan untuk memberi portal bahwa lowongan ini jika diklik oleh audien akan diarahkan kemana.
7. Setelah form sudah diisi dengan baik, untuk mempublish lowongan dapat dilakukan dengna cara mengeklik tombol Publish.
 
Mengedit Suatu Career
---------------------

Untuk mengedit suatu career baru dapat dengan cara klik button edit, kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Careers/careers-4.jpg)Berikut penjelasan dari gambar diatas :

1. ADD NEW POST, bila memang diperlukan dan tidak jadi untuk melakukan edit untuk membuat baru dapat dilakukan dengan cara mengeklik tombol ADD NEW POST.
2. Edit Title, digunakan untuk mengedit title dari suatu career.
3. Permalink, digunakan untuk mengedit suatu link yang akan ditampilkan pada list careers.
4. Divisions, digunakan untuk mengedit divisi yang sudah dipilih sebelumnya.
5. Location, digunakan untuk mengedit location yang sudah dipilih sebelumnya.
6. Work Type, digunakan untuk mengedit tipe pekerjaan yang sudah dipilih sebelumnya.
7. Job Description, digunakan untuk mengedit deskripsi pekerjaan yang sudah ada sebelumnya.
8. Link, digunakan untuk mengedit link portal job yang sudah ada sebelumnya.
9. Setelah memastikan informasi yang diinputkan sudah benar, untuk melakukan update dapat dilakukan dengan mengeklik tombol UPDATE.
