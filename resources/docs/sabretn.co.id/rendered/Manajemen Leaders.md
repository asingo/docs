Manajemen Leaders 
==================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen leaders

---

Untuk mengelola pada halaman leaders seperti gambar dibawah ini, dapat mengikuti langkah-langkah dibawah:

 ![](http://docs.grapiku.com/storage/Sabretn/Manajemen Leaders/p1.png)Pertama-tama untuk mengakses halaman untuk mengelola manajemen leaders dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/Sabretn/Manajemen Leaders/leaders-1.jpg)
============================================================================

Selanjutnya silahkan klik menu Leaders pada sidebar disebelah kiri seperti yang terlihat pada gambar diatas. Maka akan diredirect kehalaman list leaders, seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/Sabretn/Manajemen Leaders/leaders-2.jpg)
============================================================================

Pada gambar diatas terdapat beberapa menu berikut penjelasannya :

1. ADD NEW POST, digunakan untuk menambahkan leader/pimpinan baru.
2. Group post, digunakan untuk mengelompokan post berdasarkan status post itu sendiri.
3. Filter post, digunakan untuk memfilter berdasarkan tanggal dibuat/score seo maupun score readability.
4. Search Leaders, digunakan sebagai kolom pencarian.
5. Count, menampilkan jumlah post yang sudah dibuat.
6. Title, pada title post terdapat beberapa tombol, berikut penjelasannya :  
     - Edit, digunakan untuk mengedit suatu post.   
     - Trash, digunakan untuk menghapus suatu post.   
     - View, digunakan untuk melihat detail suatu post.   
     - Edit with wpbakery page builder, digunakan untuk mengubah tampilan pada suatu post (untuk tombol ini tidak direkomendasikan).
7. Terdapat 2 icon yaitu SEO score dan Readability score, berikut penjelasannya :   
     - SEO score digunakan untuk melihat seo score ini bagus atau tidaknya. jika warnanya merah maka seonya buruk, jika warnanya orange maka seonya lumayan , dan jika warnanya hijau maka seonya bagus.  
     - Readability score digunakan untuk melihat readability scoreini bagus atau tidaknya. jika warnanya merah maka seonya buruk, jika warnanya orange maka seonya lumayan, dan jika warnanya hijau maka seonya bagus.
8. Languages, digunakan untuk mengetahui post ini menggunakan bahasa indonesia atau inggris.
 
Membuat Post Leader
-------------------

Untuk membuat post baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/Sabretn/Manajemen Leaders/leaders-3.jpg)
============================================================================

Berikut tutorial untuk menambahkan suatu post pada Leaders :

1. Tambahkan bahasa terlebih dahulu pada Languages, apakah post ini akan berbahasa Indonesia atau bahasa inggris.
2. Tambahkan Title, bisa berupa nama dari seorang leader.
3. Tambahkan Jabatan.
4. Tambahkan Biografi leader.
5. Tambahkan File Foto leader yang dapat diunduh pengunjung.
6. Tambahkan Foto utama leader.
7. Setelah mengisi semua form yang perlu diisi, sekarang saatnya mempublish dapat dengan cara klik tombol publish.
 
Mengedit Post Leader
--------------------

Untuk mengedit suatu post dapat dengan cara klik Edit, kemudian akan tampil seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/Sabretn/Manajemen Leaders/leaders-4.jpg)
============================================================================

Untuk melakukan edit pada suatu post dapat mengikuti langkah-langkah dibawah ini :

1. Languages, digunakan untuk mengeset suatu post ini berbahasa Indonesia atau bahasa Inggris.
2. Title, digunakan untuk mengedit nama dari suatu post.
3. Permalink, digunakan untuk mengedit suatu url dari post.
4. Jabatan, digunakan untuk mengedit jabatan dari suatu post.
5. Biografi, digunakan untuk mengedit biografi suatu post.
6. File Foto, digunakan untuk mengedit foto yang dapat diunduh oleh pengunjung website.
7. Feature Image, digunakan untuk mengedit foto dari foto utama.
