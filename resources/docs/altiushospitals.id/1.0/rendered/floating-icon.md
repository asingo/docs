Manajemen Floating Icon
=======================

---

Dalam manajemen floating icon, anda dapat mengubah isi konten maupun link yang akan di ubah.  
![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-1.jpg)

Pengelolaan Floating Icon
-------------------------

Lakukan **LOGIN** terlebih dahulu ke admin website, lalu akan muncul seperti gambar di bawah ini

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-2.jpg)Selanjutnya sorot pada menu **TAMPILAN** dan pilih **SESUAIKAN**

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-3.jpg)Setelah melakukan langkah di atas silahkan pilih general seperti gambar dibawah ini

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-4.jpg)Setelah memilih General, pilih Custom Code sesuai dengan yang ditunjuk oleh gambar di bawah ini

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-6.jpg)Lalu edit konten yang berada di dalam box custom css yang ditunjuk dan di tandai dengan komentar

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-7.jpg)Setelah selesai mengubah, silahkan klik terbitkan, untuk menyimpan perubahan konten

 ![](http://docs.grapiku.com/storage/altius/floating-icon/floating-icon-8.jpg)Konten yang berhasil disimpan akan muncul tulisan TELAH TERBIT
