Manajemen Event
===============

---

Dalam manajemen Event, dapat dikelola melalui menu POS pada halaman admin. Manajemen cerita diantaranya membuat draf, mengategorikan, menerbitkan, menghapus.

Pengelolaan Event
-----------------

Untuk mengelola cerita klik menu **Event** pada bilah menu kiri, maka akan muncul tampilan seperti di bawah ini.

 ![](http://docs.grapiku.com/storage/altius/event/Event-1.jpg)1. Klik menu **TAMBAH BARU** atau tombol **TAMBAH BARU** untuk menambahkan konten Event baru.
2. Klik judul atau klik tombol **SUNTING** untuk mengedit postingan yang sudah tersimpan sebagai draf maupan yang sudah terbit.
3. Klik tombol **TONG SAMPAH** untuk menghapus postingan yang tersimpan ataupun yang sudah terbit.
4. Untuk mencari Event.
5. Terdapat Filtering untuk memfilter / menyaring Event yang ingin dicari.
 
Penambahan Event
----------------

Setelah klik **TAMBAH BARU** seperti pada panduan diatas. yaitu untuk menambahkan Event, maka akan muncul tampilan seperti di bawah ini:![](http://docs.grapiku.com/storage/altius/event/Event-2.jpg)

1. 1. Masukkan Judul Event
    2. Masukkan Lokasi Event
    3. Masukkan Tanggal Event
    4. Masukkan Jam Event Berlangsung
    5. Masukkan isi Event di dalam area ini, anda juga dapat mengatur model tulisan seperti **Bold**, *Italic*, dll seperti pada aplikasi penulisan pada umumnya. Dapat juga menambahkan gambar dengan klik tombol **TAMBAHKAN MEDIA**
        1. > {info} Kami merekomendasikan untuk menulis artikel terlebih dahulu di **Microsoft Word** atau di **Google Docs** kemudian di Copy Paste, untuk menghindari koneksi yang terputus
    6. Klik tombol **TETAPKAN GAMBAR ANDALAN** untuk menambah gambar utama atau sampul Event.
 
 ![](http://docs.grapiku.com/storage/altius/event/Event-3.jpg)  
1. Pilih jenis periode event.
2. Untuk menyalakan penjadwalan event silahkan centang pada checkbox Enable Post Expiration
3. Pilih Tahun Pos yang akan di jadwalkan
4. Pilih Bulan Pos yang akan di jadwalkan
5. Pilih Tanggal Pos yang akan di jadwalkan
6. Pilih Jam Pos yang akan di jadwalkan
7. Pilih Menit Pos yang akan di jadwalkan
8. Pastikan metode expire REPLACE
9. Pilih taksonomi yang akan digunakan untuk menandai kegiatan expired
 
 ![](http://docs.grapiku.com/storage/altius/event/Event-4.jpg)  
1. Review ulang seluruh bagian, apabila sudah sesuai klik tombol **TERBITKAN** untuk menerbitkan Event.
