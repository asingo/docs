Pengelolaan Grid Fasilitas
--------------------------

Sebelum melakukan penggantian, silahkan **LOGIN** terlebih dahulu ke dasbor admin website

 ![](http://docs.grapiku.com/storage/altius/grid-fasilitas/grid-fasilitas-1.jpg)Setelah melakukan login, klik menu **LAMAN** yang ada di bagian kiri

 ![](http://docs.grapiku.com/storage/altius/grid-fasilitas/grid-fasilitas-2.jpg)Pilih laman **FASILITAS** atau klik tombol **SUNTING** pada laman fasilitas seperti yang ditampilkan pada gambar di bawah ini

 ![](http://docs.grapiku.com/storage/altius/grid-fasilitas/grid-fasilitas-3.jpg)Klik tombol yang ditandai pada gambar di bawah ini untuk membuka pengaturan gaya halaman

 ![](http://docs.grapiku.com/storage/altius/grid-fasilitas/grid-fasilitas-4.jpg)Lalu akan tampil gambar seperti di bawah ini

 ![](http://docs.grapiku.com/storage/altius/grid-fasilitas/grid-fasilitas-5.jpg)Ganti CSS yang telah ditandai sesuai dengan yang anda inginkan
