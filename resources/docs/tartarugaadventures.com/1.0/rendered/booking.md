Manajemen Booking
=================

---

Dalam manajemen booking, dapat dikelola melalui menu Bookings pada halaman admin. Manajemen Cruise diantaranya melihat booking dan mengubah status booking

Pengelolaan Booking
-------------------

Untuk mengelola booking klik menu **BOOKINGS** pada bilah menu kiri seperti gambar di bawah ini

 ![](http://docs.grapiku.com/storage/tartaruga/booking/booking-1.jpg)Maka akan muncul tampilan seperti di bawah ini.

 ![](http://docs.grapiku.com/storage/tartaruga/booking/booking-2.jpg)Berikut ini adalah deskripsi dari tampilan di atas

 ![](http://docs.grapiku.com/storage/tartaruga/booking/booking-3.jpg)  
1. Klik menu **TAMBAH BARU** atau tombol **TAMBAH BARU** untuk menambahkan booking baru.
2. Klik Export to CSV untuk mengunduh data booking.
3. Klik judul atau klik tombol **SUNTING** untuk mengedit postingan yang sudah tersimpan sebagai draf maupan yang sudah terbit.
4. Klik tombol **TONG SAMPAH** untuk menghapus postingan yang tersimpan ataupun yang sudah terbit.
 
Mengubah Status Booking
-----------------------

Setelah klik **JUDUL** atau **EDIT** seperti pada panduan diatas. yaitu untuk mengubah status booking, maka akan muncul tampilan seperti di bawah ini:  
![](http://docs.grapiku.com/storage/tartaruga/booking/booking-4.jpg)

1. Bagian yang ditandai dengan nomor 1 adalah bagian detail booking
2. Pilih Status booking yang ditandai dengan nomor 2. Adapun untuk detail status yaitu (Booked = User telah melakukan booking), (Confirmation = User telah mengonfirmasi akan melakukan perjalanan dengan melakukan DP/ Pembayaran), (Canceled = User membatalkan reservasi), (End = User telah melakukan perjalanan)
3. Klik **Update** untuk menyimpan pembaruan
