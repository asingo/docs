Login &amp; Logout
==================

---

Login dan Logout adalah tutorial cara masuk ke dalam dasbor admin website dan keluar dari akun admin website. Berikut langkahnya:

Login
-----

Untuk login, buka browser dan masukkan alamat login yang telah dikirimkan, lalu muncul tampilan seperti di bawah ini. Kemudian tinggal isi akun login pada pada field/ form yang sudah disediakan yaitu:

 ![](http://docs.grapiku.com/storage/tengaran/login/login.jpg)1. Masukkan username atau email yang sudah diinformasikan
2. Masukkan password atau kata sandi yang sudah diinformasikan
3. Centangi Ingat Saya apabila ingin menyimpan data login di browser, apabila tidak cukup abaikan saja
4. Kemudian Klik Tombol Log Masuk untuk masuk ke halaman admin
 
Logout
------

Untuk logout, arahkan pointer mouse ke pojok kanan atas pada menu akun (ditandai dengan ikon akun) kemudian klik **LOG KELUAR**

 ![](http://docs.grapiku.com/storage/tengaran/login/logout.jpg)
