================================================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen events

---

Untuk mengelola pada halaman events seperti gambar dibawah ini, dapat mengikuti langkahlangkah dibawah:

![](http://docs.grapiku.com/storage/verandamc/events/ev.png)

Pertama-tama untuk mengakses halaman untuk mengelola manajemen events dapat mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/verandamc/events/cvr.png)

Untuk mengakses halaman manajemen events dapat diakses dengan menu sidebar disebelah kiri melalui tutorial dibawah yaitu :

![](http://docs.grapiku.com/storage/verandamc/events/2344.png)

1. Arahkan kursor mouse pada menu Events
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Events
 
 
Setelah masuk kehalaman All Events seperti gambar dibawah ini, berikut pembahasannya :

![](http://docs.grapiku.com/storage/verandamc/events/77667.png)

1. ADD NEW POST, digunakan untuk menambahkan offer baru.
2. Status Events, fitur disini berfungsi sebagai mengoordinasi status pada Events beserta akumulasi masing-masing status.
3. Filter, digunakan untuk mefilter semua Events, disini terdapat 4 filter yang disediakan.
4. Search, berfungsi sebagai form pencarian untuk semua offers.
5. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat beberapa button seperti :  
    \- Edit, digunakan untuk mengedit suatu post yang dipilih.  
    \- Trash, digunakan untuk menghapus suatu post yang dipilih.  
    \- View/Preview, digunakan untuk melihat suatu post yang telah dibuat.  
    \- Clone, digunakan untuk menduplicate post yang sudah ada.  
    \- New Draft, digunakan untuk mendrafting suatu post.
6. Date, berfungsi untuk melihat post ini dipublish/diupdated tanggal dan jam berapa.
7. Seo score dan Readability score, terdapat 3 warna yaitu :  
    \- Merah, scorenya kurang bagus.  
    \- Orange, scorenya lumayan bagus.  
    \- Hijau, scorenya bagus.
 
 
Mengedit Events
---------------

Untuk mengedit event dapat dengan cara klik EDIT pada button event yang dipilih, pada kasus ini kami akan mencontohkan untuk melakukan edit pada Social Event. Setelah diklik maka akan tampil seperti gambar dibawah ini :

![](http://docs.grapiku.com/storage/verandamc/events/evnt.png)

![](http://docs.grapiku.com/storage/verandamc/events/3.png)

Berikut penjelasannya :

1. Title, digunakan untuk mengedit judul event yang sudah ada.2. Permalink, digunakan untuk mengedit link/url suatu event.
2. Hero Banner, untuk menganti hero banner dapat clik pada button pensil yang telah ditandai
 &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1920x1080px. 4. Events, digunakan untuk mengubah title section Events
5. Social Events, digunakan untuk mengubah heading section Social Events
6. Description, digunakan untuk mengubah description dari social events
7. Button Get Inquiry, digunakan untuk mengubah judul pada button ataupun link yang ditautkan
8. Gallery, digunakan untuk menambahkan/menganti image yang dislide.
 &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1920x1080px. 10. Venues, title dari Social Events Venues
11. Hero img dari function hall
12. Title, function hall
13. description dari function hall
14. Button venue map digunakan untuk menambahkan link pdf dari venue map.
15. Button get inquiry digunakan untuk menambakan link pada get inquiry.
 
![](http://docs.grapiku.com/storage/verandamc/events/667.png)

![](http://docs.grapiku.com/storage/verandamc/events/787.png)

1. Plan for other events, digunakan untuk mengedit title pada other events.
2. Post Grid Other Event, digunakan untuk mengelola grid events.
3. Offers, digunakan untuk mengedit title pada offers.
4. Special Deals Package, digunakan untuk mengedit special deals package.
5. Post Grid, digunakan untuk mengedit grid dari offers.
6. Featured Image, usahakan gambarnya sama dengan hero utama
 &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1920x1080px. 8. Events Category, tambahkan/edit category sesuai dengan yang diinginkan.
9. Setelah melakukan semua perubahan. Selanjutnya tekan tombol Perbarui/Publish.
