Logout
======

---

<a name="section-1"></a>

Logout adalah tutorial cara keluar dari akun admin website. Berikut langkahnya

Logout
------

Untuk logout, arahkan pointer mouse ke pojok kanan atas pada menu akun (ditandai dengan ikon  
akun) kemudian klik **Log Keluar**

Maka akun akan dilogoutkan dan aktifitas editting akan memerlukan akses untuk login terlebih  
dahulu.
