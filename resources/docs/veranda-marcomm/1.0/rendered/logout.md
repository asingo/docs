Logout
======

---

Logout adalah tutorial cara keluar dari akun admin website. Berikut langkahnya

<a name="section-1"></a>

Logout
------

Untuk logout, arahkan pointer mouse ke pojok kanan atas pada menu akun (ditandai dengan ikon akun) kemudian klik **Log Keluar**

![](http://docs.grapiku.com/storage/varenda marcomm-1/logout/Logout-Marcomm.png)

Maka akun akan dilogoutkan dan aktifitas editting akan memerlukan akses untuk login terlebih dahulu.
