Manajemen Careers
=================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen careers

---

Untuk mengelola pada halaman careers seperti gambar dibawah ini, dapat mengikuti langkah-  
langkah dibawah:  
![](http://docs.grapiku.com/storage/veranda-marcomm/careers/carrers1.png)

Pertama-tama untuk mengakses halaman untuk mengelola manajemen careers dapat mengakses  
dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses halaman  
dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/signnature/signature-1.png)Untuk mengakses halaman manajemen careers dapat diakses dengan mengeklik menu careers  
yang berada pada sidebar seperti gambar dibawah, setelah mengeklik maka akan diarahkan ke  
halaman manajemen careers seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/careers/careers-1.png) Berikut pembahasan tutorial pada gambar diatas :

1. Careers, digunakan untuk membuka halaman Careers.
2. All Careers. sub menu careers digunakan untuk membuka list all careers
3. Add New Post, digunakan untuk membuat suatu career baru
4. Status Post, digunakan untuk mengetahui status post tersebut apakah terpublish atau terdrafting
5. Filter, digunakan untuk mengelompokkan data berdasarkan filter yang telah disediakan
6. Search, digunakan untuk mencari suatu career
7. Title, digunakan untuk mengelola suatu post disini terdapat 4 button yaitu :  
    \- EDIT, digunakan untuk mengedit suatu post.  
    \- TRASH, digunakan untuk menghapus suatu post.  
    \- VIEW, digunakan untuk melihat detail suatu post.  
    \- EDIT WITH WPBAKERY PAGE BUILDER, digunakan untuk mengedit tampilan (pada button ini  
    tidak direkomendasikan untuk digunakan).
8. Date, digunakan untuk mengetahui list suatu post terbit
9. Seo score dan Readability score, terdapat 3 warna yaitu :  
    \- Merah, scorenya kurang bagus.  
    \- Orange, scorenya lumayan bagus.  
    \- Hijau, scorenya bagus.
 
Membuat Suatu Career
--------------------

Untuk membuat suatu career baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil   
seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/careers/careers-2.png) Berikut pembahasan dari tutorial diatas :

1. Add Title, digunakan untuk menambahkan judul baru pada suatu career.
2. Location, digunakan untuk memberikan informasi di kota mana lowongan ini tersedia.
3. Position Type, digunakan untuk memberikan informasi posisi apa yang akan dibuka.
4. Open Date, digunakan untuk memberikan tanggal posisi yang akan dibuka
5. Job Description, digunakan untuk memberi penjelasan tentang job desk dari suatu career.
6. Benerfits, digunakan untuk memberikan informasi tentang benefit yang didapatkan.
7. Responsibilities, digunakan untuk memberikan informasi tentang tanggung jawab yang  
    diemban.
8. Qualifications, digunakan untuk memberikan informasi tentang kualifikasi untuk pekerjaan yang  
    akan dibuat.
9. Link, digunakan untuk memberi portal bahwa lowongan ini jika diklik oleh audien akan   
    diarahkan kemana.  
    &gt;{info} Untuk mengisi link harus menyertakan http:// atau https:// dan apabila mengisi alamat  
    email yang dituju maka penulisan harus mailto:.
10. Setelah form sudah diisi dengan baik, untuk mempublish lowongan dapat dilakukan dengan cara mengeklik tombol Publish.
 
Mengedit Suatu Career
---------------------

Untuk mengedit suatu career baru dapat dengan cara klik button edit, kemudian akan tampil  
seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/careers/careers-3.png)Berikut penjelasan dari gambar diatas :

1. Title, digunakan untuk mengedit judul suatu karier.
2. Permalink. digunakan untuk mengedit url suatu karier.
3. Location, digunakan untuk mengedit lokasi karier.
4. Position Type, digunakan untuk mengedit position type.
5. Open Date, digunakan untuk mengedit tanggal karier dibuka
6. Job Description, digunakan untuk mengedit deskripsi pekerjaan.
7. Benefits, digunakan untuk mengedit benefit.
8. Responsibilities, digunakan untuk mengedit tanggung jawab pada posisi tersebut.
9. Qualifications, digunakan untuk mengedit syarat dan ketentuan.
10. Link Application, digunakan untuk mengedit link pendaftaran atas posisi yang dibuka &gt;{info} Untuk mengisi link harus menyertakan http:// atau https:// dan apabila mengisi alamat email yang dituju maka penulisan harus mailto
11. Setelah memastikan informasi yang diinputkan sudah benar, untuk melakukan update dapat  
    dilakukan dengan mengeklik tombol UPDATE.
