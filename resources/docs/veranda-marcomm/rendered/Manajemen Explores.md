Manajemen Explores
==================

Dalam langkah-langkah kali ini akan membahas tentang cara manajemen explore

---

Untuk mengelola pada halaman explores seperti gambar dibawah ini, dapat mengikuti langkah-  
langkah dibawah:  
  
![](http://docs.grapiku.com/storage/veranda-marcomm/explore/explores-1.png)

Pertama-tama untuk mengakses halaman untuk mengelola manajemen Explores dapat  
mengakses dashboard admin yang telah diberikan oleh team grapiku. Sesudah mengakses  
halaman dashboard admin maka akan disuguhkan variasi menu dan fitur seperti gambar dibawah ini :  
  
![](http://docs.grapiku.com/storage/veranda-marcomm/signnature/signature-1.png)

Untuk mengakses halaman manajemen explore dapat diakses dengan menu sidebar disebelah kiri   
melalui tutorial dibawah yaitu :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/explore/explores-3.png)1. Arahkan kursor mouse pada menu Posts
2. Setelah tampil seperti gambar diatas maka akan muncul sub menu, dan pilih All Posts
 
 
Setelah masuk kehalaman All Posts seperti gambar dibawah ini, berikut pembahasannya :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/explore/explore-3.png)1. ADD NEW POST, digunakan untuk menambahkan explore baru.
2. Status explore, fitur disini berfungsi sebagai mengoordinasi status pada explore beserta  
    akumulasi masing-masing status.
3. Filter, digunakan untuk mefilter semua explore, disini terdapat 6 filter yang disediakan.
4. Search, berfungsi sebagai form pencarian untuk semua explore.
5. Title, pada field title disini dapat digunakan untuk mengelola suatu post dan juga terdapat  
    beberapa button seperti :  
    \- Edit, digunakan untuk mengedit suatu post yang dipilih.  
    \- Trash, digunakan untuk menghapus suatu post yang dipilih.  
    \- View/Preview, digunakan untuk melihat suatu post yang telah dibuat.  
    \- Clone, digunakan untuk menduplicate post yang sudah ada.  
    \- New Draft, digunakan untuk mendrafting suatu post.
6. Author, berfungsi menampilkan username/name dari pembuat suatu post.
7. Categories, berfungsi menampilkan category pada suatu post
8. Date, berfungsi untuk melihat post ini dipublish/diupdated tanggal dan jam berapa.
9. Seo score dan Readability score, terdapat 3 warna yaitu :  
    \- Merah, scorenya kurang bagus.  
    \- Orange, scorenya lumayan bagus.  
    \- Hijau, scorenya bagus.
 
Membuat Post
------------

Untuk membuat post baru dapat dengan cara klik ADD NEW POST, kemudian akan tampil seperti  
gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/post/post1-marcomm1.png)1. Add title, digunakan untuk menambahkan title pada post.
2. Description, digunakan untuk menambahkan isi dari suatu post yang akan dibuat.
3. Excerpt, digunakan menambahkan sebuah deskripsi singkat.
4. Categories, digunakan untuk menambahkan categories.
5. Fetaured Image, digunakan untuk menambahkan gambar utama yang akan ditampilkan  
    pada list explore.  
    &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1920x1080px.
6. Slider Aktif, digunakan untuk menampilkan pada slider. Jika tidak diperlukan untuk di  
    hightlight jadi tidak perlu di aktifkan.
7. Publish, digunakan untuk mempublish post yang sudah dibuat.
 
Mengedit Post
-------------

Untuk mengedit suatu post dapat dilakukan dengan cara mengeklik title/button edit dari suatu  
post dihalaman all post , kemudian akan tampil seperti gambar dibawah ini :

 ![](http://docs.grapiku.com/storage/veranda-marcomm/post/posedit1.png)1. Title, digunakan untuk mengedit title pada post.
2. Permalink, digunakan untuk mengedit url/link yang sudah ada.
3. Description, digunakan untuk mengedit isi dari suatu post yang akan dibuat.
4. Excerpt, digunakan mengedit sebuah deskripsi singkat.
5. Categories, digunakan untuk mengedit categories.
6. Fetaured Image, digunakan untuk mengedit gambar utama yang akan ditampilkan pada list  
    explore.  
    &gt;{info} untuk ukuran gambar diwajibkan menggunakan ukuran 1920x1080px.
7. Slider Aktif, digunakan untuk menampilkan pada slider. Jika tidak diperlukan untuk di  
    hightlight jadi tidak perlu di aktifkan.
8. Publish, digunakan untuk mempublish post yang sudah diedit.
