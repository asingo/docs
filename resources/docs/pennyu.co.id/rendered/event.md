Manajemen Data Event
====================

---

Dalam manajemen Data Event, anda dapat memberikan informasi mengenai event yang akan datang, dan pada Halaman Event juga memuat event yang telah lampau.

Kelola Event
------------

Untuk mengelola event, klik menu **EVENT** pada bilah menu di samping kiri, lalu muncul tampilan sebagai berikut:

1. Klik menu TAMBAH BARU atau tombol TAMBAH BARU untuk menambahkan cerita baru
2. Klik judul atau klik tombol SUNTING untuk mengedit proyek yang sudah tersimpan
3. Klik TONG SAMPAH untuk menghapusan postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari proyek
5. Terdapat filtering untuk memfilter proyek yang dicari
 
Menambahkan Event
-----------------

Untuk menambahkan event, silahkan klik tombol **TAMBAH BARU** yang berada pada gambar di atas **petunjuk nomor 1**, lalu akan tampil seperti gambar di bawah ini:

1. Pada kolom **TAMBAHKAN JUDUL**, silahkan masukkan Judul Event yang anda inginkan
2. Masukkan Tanggal Pelaksanaan Event
3. Masukkan Jam Pelaksanaan Event
4. Masukkan Tempat atau Platform dimana event akan diselenggarakan
5. Masukkan Deskripsi Event
6. Pada bagian kanan kolom Gambar Andalan, Pilih **Tetapkan Gambar Unggulan** untuk menambahkan gambar atau sampul event
 
 <center>{info} Kami merekomendasikan ukuran gambar yaitu **900px x 600px**</center>### Atur Kategori dan Kadalursa

Pada bagian event terdapat fitur dimana event yang ditambahkan bisa otomatis menjadi kadaluarsa sesuai tanggal yang diatur, seperti gambar di bawah ini

1. Pada bagian kanan di kolom **PERIODE EVENT**, pilih kategori event
2. Pada bagian kanan di kolom **PUBLISH PRESS,** centang **Enable Post Expiration**
3. Atur **tahun** berakhirnya event
4. Atur **bulan** berakhirnya event
5. Atur **tanggal** berakhirnya event
6. Atur **jam** berakhirnya event
7. Atur **menit** berakhirnya event
8. Bagian **How To Expire** di atur menjadi **Taxonomy: Replace**
9. **Expiration Taxonomies** di set menjadi Kegiatan Lampau
 
#### Finalisasi

Pastikan review ulang semua bagian, apabila sudah sesuai, klik tombol **TERBITKAN** untuk menerbitkan event.
