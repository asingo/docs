Managemen Data Sertifikasi
==========================

---

Dalam manajemen Data Sertifikasi, anda dapat mengelola sertifikat dari produk yang sudah ditambahkan.

Pengelolaan Sertifikasi
-----------------------

Untuk pengelolaan data sertifikasi, klik menu **Data Sertifikasi** pada bilah menu kiri, maka akan muncul tampilan seperti di bawah ini

 ![](http://docs.grapiku.com/storage/pennyu/sertifikat/SERTIFIKAT-1.jpg)1. Klik menu **TAMBAH BARU** atau tombol **TAMBAH BARU** untuk menambahkan cerita baru
2. Klik judul atau klik tombol **SUNTING** untuk mengedit sertifikat yang sudah tersimpan
3. Klik **TONG SAMPAH** untuk menghapusan postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari sertifikat
5. Terdapat filtering untuk memfilter sertifikat yang dicari
 
Menambah Sertifikasi
--------------------

Untuk menambahkan sertifikasi, silahkan klik tombol **TAMBAH BARU** yang berada pada gambar di atas **petunjuk nomor 1**, lalu akan tampil seperti gambar di bawah ini:

 ![](http://docs.grapiku.com/storage/pennyu/sertifikat/SERTIFIKAT-2.jpg)1. Pada kolom **TAMBAHKAN JUDUL**, silahkan masukkan Judul Sertifikasi sesuai dengan sertifikasi yang akan di upload
2. Pilih berkas sertifikasi dengan cara klik tombol **Tambah Berkas** pada bagian **Berkas Sertifikasi**, lalu muncul tampilan seperti dibawah ini:
 
 
 ![](http://docs.grapiku.com/storage/pennyu/sertifikat/SERTIFIKAT-3.jpg)1. 1. 1. **Drag &amp; Drop** File Sertifikasi dari file explorer Komputer anda, atau menggunakan menu **unggah berkas.**
        2. Jika sudah selesai klik tombol PILIH, untuk memilih berkas yang digunakan
         
         <center>{warning} File Sertifikasi harus berformat PDF</center>
 
 
3\. Ketik Nama Produk yang akan ditambahkan sertifikatnya di bagian **Kategori Sertifikasi**   
4\. Review ulang semua data, setelah selesai klik **TERBITKAN** untuk menerbitkan Data Sertifikasi
