Manajemen Data Event
====================

---

Dalam manajemen Data Event, anda dapat memberikan informasi mengenai event yang akan datang, dan pada Halaman Event juga memuat event yang telah lampau.

Kelola Event
------------

Untuk mengelola event, klik menu **EVENT** pada bilah menu di samping kiri, lalu muncul tampilan sebagai berikut:

1. Klik menu TAMBAH BARU atau tombol TAMBAH BARU untuk menambahkan cerita baru
2. Klik judul atau klik tombol SUNTING untuk mengedit proyek yang sudah tersimpan
3. Klik TONG SAMPAH untuk menghapusan postingan yang tersimpan ataupun yang sudah terbit
4. Untuk mencari proyek
5. Terdapat filtering untuk memfilter proyek yang dicari
 
Menambahkan Event
-----------------

Untuk menambahkan event, silahkan klik tombol **TAMBAH BARU** yang berada pada gambar di atas **petunjuk nomor 1**, lalu akan tampil seperti gambar di bawah ini:

1. Pada kolom TAMBAHKAN JUDUL, silahkan masukkan Judul Event yang anda inginkan
2. Masukkan Tanggal Pelaksanaan Event
