Managemen Data Sertifikasi
==========================

---

Dalam manajemen Data Sertifikasi, anda dapat mengelola sertifikat dari produk yang sudah ditambahkan.

Pengelolaan Sertifikasi
-----------------------

Untuk pengelolaan data sertifikasi, klik menu **Data Sertifikasi** pada bilah menu kiri, maka akan muncul tampilan seperti di bawah ini

1. Klik menu **TAMBAH BARU** atau tombol **TAMBAH BARU** untuk menambahkan cerita baru
