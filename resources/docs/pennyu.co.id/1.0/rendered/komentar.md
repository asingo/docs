Manajemen Komentar
==================

---


Dalam bagian ini akan dijelaskan bagaimana cara manajemen komentar antara lain: Membalas, Membuat, Menghapus, Menolak dan Menyunting komentar yang terdapat pada bagian Tanya Pennyu. Link: <span style="text-decoration: underline; color: #236fa1;">Tanya Pennyu</span>

Kelola Komentar
---------------

Untuk mengelola komentar maupun melihat komentar yang dikirimkan oleh user maupun admin melalui menu **Komentar** di bagian sebelah kiri, dan akan muncul seperti gambar berikut ini:

1. Klik **TOLAK** untuk menolak komentar, atau menghapus komentar dari tampilan depan atau laman **Tanya Pennyu**
2. Klik judul atau klik tombol **SUNTING** untuk mengedit Komentar yang sudah tersimpan
3. Klik **TONG SAMPAH** untuk menghapusan komentar yang tersimpan
4. Untuk mencari Komentar
5. Tombol **STICK** digunakan untuk Pin komentar
6. Tombol **CLOSE** digunakan untuk menutup komentar agar tidak bisa dibalas
7. Terdapat filtering untuk memfilter CTA Pos yang dicari
 
Menambahkan Komentar
--------------------

Penambahan komentar dapat dilakukan dengan menuju laman **Tanya Pennyu.** Melalui Homepage (Tampilan di bawah ini) atau klik link: <span style="text-decoration: underline; color: #236fa1;">Tanya Pennyu</span>

setelah terbuka scroll down sampai menemukan bagian **Kolom Diskusi** dengan tampilan seperti dibawah ini:

 <center>{info} Pastikan anda sudah login terlebih dahulu menggunakan Akun Admin</center>1. Untuk menambah komentar baru silahkan ketikkan komentar pada bagian ***Join the Discussion***
2. Untuk membalas komentar yang sudah ada, pilih tombol **Reply**
3. Untuk mendukung komentar, pilih tombol dengan **Icon Jempol**
